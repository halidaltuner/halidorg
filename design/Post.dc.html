Notes on an htmx-first admin

2026-10-1612 min read#htmx #go #admintr: not yet

The admin for this site has one rule: a full page reload should never be necessary while editing. Every form posts to a handler that returns a fragment, and htmx swaps it in. No client router, no store, no build step beyond Tailwind-free CSS.

Why not an SPA

An SPA would duplicate the validation, the routing and the templates that already live on the server. With fragments the server stays the single source of truth, and every form still works without JavaScript1, which matters for the one time a CDN fails at 2am.

1 Progressive enhancement here means the plain form posts and redirects; htmx only intercepts when present.

Autosave meets revisions

Autosave fires on keyup changed delay:800ms. The first version wrote a revision on every save; a single post collected 900 revisions in an afternoon.

internal/admin/revisions.go 
// coalesce autosaves into one revision per 10 minutes
func (s *Store) SaveDraft(ctx context.Context, e Entry) error {
    last, _ := s.LastRevision(ctx, e.ID)
    if last != nil && time.Since(last.At) < 10*time.Minute {
        return s.UpdateRevision(ctx, last.ID, e.Body)
    }
    return s.InsertRevision(ctx, e.ID, e.Body)
}
tip
Explicit saves (⌘S) always create a new revision. Only autosaves coalesce.

Out-of-band swaps

Saving the editor also needs to update the status badge in the top bar and the revision count in the side panel. hx-swap-oob handles both from the same response.

editor.html handler.go
html
1<!-- save returns the form + oob badge + oob revision count -->
2<form hx-post="/admin/entries/42"
3      hx-trigger="keyup changed delay:800ms, submit"
4      hx-target="this" hx-swap="outerHTML">
5  <textarea name="body">{{.Body}}</textarea>
6</form>
7
8<span id="status" hx-swap-oob="true">draft · saved 14:02</span>
9<span id="rev-count" hx-swap-oob="true">34</span>
terminal

ok halid/internal/admin 0.412s
warning
OOB targets must exist on every page that can trigger the save, or htmx silently drops them.
